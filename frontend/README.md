# Dependency-smells-detector frontend

React Web Application Layer for visualising backend analysis JSON artefacts.

## Features

- Loads the `.json` output generated by the backend.
- Renders the dependency graph with Cytoscape.js.
- Colors nodes by highest smell severity:
  - Critical: red
  - High: orange
  - Medium: yellow
  - Low: blue
  - No smells: green
- Filters the graph by smell type and severity.
- Shows node metadata, SSSS score, evidence, and detector source.

## Commands

Install dependencies from the lockfile:

```powershell
npm ci
```

Run the development server:

```powershell
npm run dev
```

Run the frontend logic and component test suite:

```powershell
npm run test
```

Run the test suite with coverage:

```powershell
npm run test:coverage
```

This command prints statement, branch, function, and line coverage in the terminal and generates an interactive HTML report at `coverage/index.html`.

Build the production bundle:

```powershell
npm run build
```
